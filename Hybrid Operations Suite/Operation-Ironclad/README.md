# 🛡️ Operation Ironclad: Purple Team Simulation Lab

## Real-Time Network Reconnaissance Detection & SOC Telemetry Pipeline

## 🚀 Project Overview

**Operation Ironclad** is a self-hosted, bare-metal Security Operations Center (SOC) telemetry pipeline designed to detect, aggregate, log, and visualize malicious adversarial network-reconnaissance activity in real time.

The project demonstrates a **dual-perspective Purple Team simulation** conducted on physical hardware.

The adversarial side uses an external handheld **GPD Win 1** as the attack node to perform an aggressive network-scanning sweep.

The defensive side captures the resulting network telemetry, transports the data through a local observability pipeline, and presents the resulting security information through centralized SIEM dashboards for analyst investigation.

# 🏗️ Core Architecture Stack

| Layer                    | Technology       | Function                                         |
| ------------------------ | ---------------- | ------------------------------------------------ |
| **Adversary Node**       | GPD Win 1        | External attack and reconnaissance platform      |
| **Network Sensor**       | Zeek             | Network traffic monitoring and protocol analysis |
| **Log Shipper**          | Grafana Promtail | Collects and forwards security logs              |
| **Log Database**         | Grafana Loki     | Stores and indexes telemetry                     |
| **Visualization / SIEM** | Grafana          | Dashboarding and analyst investigation           |

# 🧪 Purple Team Methodology

The project follows a straightforward adversary-to-detection workflow:

```text id="a4h8kg"
1. Adversarial Activity
          │
          ▼
2. Network Traffic Generated
          │
          ▼
3. Zeek Observes Activity
          │
          ▼
4. Logs Forwarded by Promtail
          │
          ▼
5. Telemetry Stored in Loki
          │
          ▼
6. Grafana Visualizes Activity
          │
          ▼
7. Analyst Investigates
```

This methodology allows the offensive activity and defensive telemetry to be examined as a single exercise rather than as isolated Red and Blue Team activities.
